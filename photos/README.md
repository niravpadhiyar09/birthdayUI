# Nisha's photos go here

Drop cut-out photos (subject on a **transparent background**, PNG) into this folder:

    photos/nisha-1.png
    photos/nisha-2.png
    photos/nisha-3.png
    photos/nisha-4.png

Any `.png` / `.jpg` / `.jpeg` / `.webp` here is picked up automatically (sorted by
filename) — no code change needed. 3–4 photos look best. Until you add real ones,
the film shows numbered placeholder portraits so you can preview each layout.

Tip for cut-outs: use any "remove background" tool, export as PNG. Portrait /
upper-body framing composites best into the tree and polaroids.
